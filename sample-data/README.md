# Sample datasets

Three CSV files to try the app with. On the **Data** page, drop a file onto "Bring in your sales data", check the preview, then click Import. Use **Restore sample data** on the Data page to go back to the built-in data.

| File | What it shows |
| --- | --- |
| `1_bakery_chain_clean.csv` | A clean file with the standard columns (`date, store, category, product, orders, units, revenue, cost`): 3 stores, Jan to Mar 2026. Imports with no fixes needed. |
| `2_messy_till_export.csv` | A till export with different column names (`Day, Branch, Dept, Item, Qty, Amount`), `dd/mm/yyyy` dates, `$` amounts, store names in different capitals, a few blank cells and repeated rows. Shows the cleaning report. |
| `3_retail_chain_trends.csv` | Jan 2025 to Jun 2026 for 4 stores. Suburb slowly declines, Online grows and Earbuds keep rising, so the trend chart, heatmap and insights have something to show. |

The numbers are made up.
